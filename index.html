方案一

坦桑 Safari + 莫西小镇慢生活

莫西连住2晚 · D11晚或D12晚弹性飞回

地图路线轨迹

JRO机场 ➔ 阿鲁沙 ➔ 塔兰吉雷 ➔ 恩戈罗 ➔ 塞伦盖蒂中部 ➔ 北塞(2晚) ➔ 莫西小镇(连住2晚) ➔ JRO返程
D1｜抵达乞力马扎罗 JRO · 阿鲁沙

接机后前往阿鲁沙，入住并休息；根据航班时间安排轻松活动。

D2｜塔兰吉雷国家公园

进入塔兰吉雷 Safari，寻找象群、 baobab 树及草原动物，傍晚返回营地/旅馆。

D3｜恩戈罗保护区

前往恩戈罗区域，沿途欣赏高地景观；可安排火山口周边或保护区内住宿。

D4–D5｜塞伦盖蒂中部

在塞伦盖蒂中部进行多次游戏驱车，追踪狮子、猎豹及其他草原动物。

D6–D7｜北塞伦盖蒂（2晚）

重点关注大迁徙兽群与马拉河周边活动；具体过河情况取决于当时兽群位置和天气。

D8–D9｜莫西小镇（连住2晚）

从 Safari 区域返回莫西，安排休整、洗衣、咖啡体验或远眺乞力马扎罗。

D10–D11｜返程弹性

按机票安排前往 JRO；可选择 D11 晚或 D12 晚航班，预留转场缓冲。

以上为路线示意，实际行程、住宿、交通及动物迁徙位置请以旅行社确认方案为准。

方案二

安博塞利雪山 + 坦桑大迁徙 + 肯尼亚跨国

跨国全景 · D12晚或D13早弹性飞回

地图路线轨迹

NBO内罗毕 ➔ 安博塞利 ➔ 阿鲁沙 ➔ 恩戈罗 ➔ 北塞(3晚) ➔ Isebania口岸 ➔ 马赛马拉 ➔ 新月岛 ➔ 内罗毕返程
D1｜抵达内罗毕 NBO · 安博塞利

抵达后前往安博塞利，天气晴朗时可欣赏乞力马扎罗山景。

D2｜安博塞利国家公园

安排全天 Safari，重点观察象群与雪山背景；夜宿安博塞利周边。

D3｜跨境前往阿鲁沙

经边境及交通衔接进入坦桑尼亚，前往阿鲁沙休整。

D4｜恩戈罗保护区

前往恩戈罗区域，安排景观与野生动物体验。

D5–D7｜北塞伦盖蒂（3晚）

留出较多时间在北塞伦盖蒂追踪迁徙兽群，关注马拉河周边动态。

D8｜Isebania 口岸跨境

从坦桑尼亚进入肯尼亚，需确认车辆、导游及边境手续安排。

D9–D10｜马赛马拉国家保护区

安排游戏驱车寻找大型猫科动物及迁徙兽群；住宿位置影响每日进园时间。

D11｜新月岛 / 内罗毕

可安排新月岛步行体验（以实际开放与预订为准），之后前往内罗毕。

D12–D13｜返程弹性

按国际航班安排从内罗毕返程，建议预留跨境及陆路交通缓冲。

以上为路线示意，实际行程、住宿、交通及动物迁徙位置请以旅行社确认方案为准。

方案三

3晚死守大迁徙 + 桑岛果冻海度假

极至海岛 · D12由桑岛(ZNZ)直接飞回

地图路线轨迹

JRO落地 ➔ 塔兰吉雷 ➔ 恩戈罗 ➔ 塞伦盖蒂中部 ➔ 北塞(死守3晚) ➔ 桑给巴尔岛(ZNZ) ➔ 桑岛直飞返程
D1｜抵达 JRO · 塔兰吉雷

接机后前往塔兰吉雷，安排首日 Safari。

D2｜恩戈罗区域

前往恩戈罗区域，欣赏高地景观并安排野生动物体验。

D3｜塞伦盖蒂中部

进入塞伦盖蒂中部，开始追踪迁徙与草原动物。

D4–D6｜北塞伦盖蒂（连续3晚）

尽量减少长距离转场，集中在北塞伦盖蒂活动；兽群及河渡情况无法提前保证。

D7｜前往桑给巴尔岛 ZNZ

根据航班安排从 Safari 区域前往机场，飞往桑给巴尔岛。

D8–D10｜桑给巴尔海岛度假

安排海滩休闲、海上活动或石头城游览；活动可根据团队兴趣选择。

D11–D12｜桑岛返程

从 ZNZ 直接返程或经其他枢纽转机，需以实际航班为准。

以上为路线示意，实际行程、住宿、交通及动物迁徙位置请以旅行社确认方案为准。

方案四

先登顶乞力马扎罗 + 坦桑大迁徙

极客挑战 · D12晚或D13早从 JRO 飞回

地图路线轨迹

JRO落地 ➔ 乞力马扎罗(Marangu路线) ➔ 塔兰吉雷 ➔ 恩戈罗 ➔ 北塞(2晚) ➔ 阿鲁沙休整 ➔ JRO返程
D1｜抵达 JRO · 登山准备

前往登山集合点，检查装备并听取向导说明。

D2–D6｜乞力马扎罗 Marangu 路线

按登山团队安排逐日上升、适应海拔并冲顶；具体天数、营地和节奏需由专业运营方确认。

D7｜下撤与恢复

下撤后返回住宿点，休息并评估身体状态。

D8｜塔兰吉雷国家公园

开始 Safari 行程，安排塔兰吉雷游戏驱车。

D9｜恩戈罗区域

前往恩戈罗区域，体验火山口及周边野生动物。

D10–D11｜北塞伦盖蒂（2晚）

在北塞伦盖蒂安排 Safari，关注迁徙兽群活动。

D12｜阿鲁沙休整

返回阿鲁沙，作为登山与 Safari 后的恢复和返程缓冲日。

D12晚 / D13早｜JRO 返程

根据国际航班选择返程时间；请与旅行社确认登山结束日期和航班衔接。

以上为路线示意，实际行程、住宿、交通及动物迁徙位置请以旅行社确认方案为准。
